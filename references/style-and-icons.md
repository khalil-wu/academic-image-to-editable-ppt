# 风格与图标获取

## 1. 从内容决定关系

先列模块和边，再做视觉。映射/汇合与调用/返回闭环是不同的关系；不要因为线条形状相似就画成循环。系统图要说明谁执行、调用什么、结果返回哪里；研究内容图要说明研究项落在哪个系统能力。

用户提供参考时，观察字重、图标风格、配色、留白和走线。新图通常采用两到三个协调色相；复刻则遵循源图，不擅自改色。

## 2. 素材只用两条主路线

1. 抠取用户原图或其提供/允许使用的原资产，保留原始像素、透明度和视觉身份。
2. 真正调用图像 API 生成新的高分辨率素材，直接使用输出像素。

用户已有合法 SVG/原生图标源时可直接用。禁止把任何位图描摹成 SVG，也不自己拼一个简笔图来顶替用户要求的插画。

同语义素材可复用以维持一致。同一套图标按实际前景统一视觉重量，保持宽高比；不要用颜色量化、模糊或过度锐化硬做一致。

## 3. 生成提示词

语义、风格、配色、尺寸需求说清即可，避免长串互相冲突的约束。例如：

> 原创学术功能图标：脑电设备、Agent 机器人、数据读取、滤波、模型推理、报告。深紫轮廓、白色与柔和蓝紫填充，少量玫红；清晰连续线条、减少卡通。各图标完整独立，留足间隔，无文字、阴影、模块边框和流程箭头。

主图标优先单独大尺寸生成；图标表适合小功能图标，不能因一张表塞太多对象导致每格不足。记录实际输出尺寸，不能只相信请求的尺寸。

生成模型按用户配置选择，不固定为 Sunburst。Nano Banana、GPT Image 等同样适用，其他模型也可接入。使用匹配的工具或提供者 API；使用 ImageGen 时遵循其技能合同。已有配置和 API 授权持续有效，保留真实原图与提示词，不在仓库写密钥。具体选择见[模型与接口](image-models.md)。

## 4. 参考顶会图片

需要网络参考时实际打开原论文图，记录链接、图号和设计观察。用户要求至少 10 张，就实际看够 10 张，不把搜到的论文标题数量当作看图数量。借鉴字体、配色和层级，不迁移他人的科研逻辑。
