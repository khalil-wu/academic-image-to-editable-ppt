# 通用图片复刻与字体匹配

## 1. 按原图，而不是套模板

保持画布比例、所有文字、层级、区域位置、图标语义、配色与关系。截图、海报、流程图和论文图均适用。源图不是论文风格时，不自动套两三色、苹方或 Times New Roman；用户明确的字体要求优先。

复刻分为两部分：原生重建结构，抠取/生成视觉素材。禁止位图描摹，包括图标、照片、热图、波形及自己生成的素材。已有真实 SVG 可保留源路径，但不得把位图追踪成 SVG。

## 2. 元素清单

放大查看并记录：

- 全部字词、单位、标点、大小写、换行和字体层级；图内的小标签也不能漏。
- 原生对象：标题、说明、表格、模块框、分隔线、流程箭头。
- 视觉素材：机器人、设备、图标、照片、曲线图、热图等，每个语义对象独立取材。
- 图中不可辨识的内容；不能自己补造数字、数据或标签。

OCR 后逐字核对。不要把图标误识别为字，也不要把报告里的无字灰短线当成真实正文。图表缺少数据时保留原图抠图，不能生成新的曲线冒充原始实验结果。

## 3. 字体识别

先检查可用的源 PPT/SVG/PDF 元数据；只有位图时对比候选字形、字宽、字重和自然比例。主标题、分区标题、正文、小标注分别比较。

```powershell
python scripts/match_font.py reference.png --crop 40 6 422 62 --text 'EEGAgent Live' --fonts 'C:/Windows/Fonts/Roboto-Bold.ttf' 'C:/Windows/Fonts/segoeuib.ttf' --output title-font.json
```

脚本接受 TTF、OTF 和 TTC（首个字体面），输出视觉近似匹配；相似度不是识别概率。裁剪必须只包含该段字，不能混入边框/图标。匹配后还需在目标应用实际导出，核对字体回退和自然字宽。不把文字转轮廓换取表面一致。

## 4. 清晰度与 1:1

源图裁片不重采样，以原像素嵌入。抠取可清除背景/旧文字区域，但不能重绘边缘、量化颜色或清理掉科研曲线。图片内存在文字时，先将对应部分真正移出素材，再放原生文本；不能只用白块盖住旧字。

原生文字/几何和位图来自不同渲染器，边缘抗锯齿可能不同；字体也可能只是近似。对比完整图和重要局部，不用一个像素误差分数宣称 100% 一致。

此前要求原创时，API 图标保持功能语义和视觉层级，但形象会与参考不同，不能同时宣称图标也完全一致。用户接受抠原图时，无损裁片是保留外观最直接的选择。

## 5. 图表与屏幕内容

波形、频谱、头皮图、热图保留原像素，不通过描摹逼出曲线节点。原始数据另有提供时，可以用数据生成原生图表；这与从图片追踪轮廓不同。

电脑/手机外壳可抠出，屏幕中需要可编辑的文字实际清空；波形、控件等分别抠取放回。不要把整块有字屏幕当成“每个字可编辑”。
