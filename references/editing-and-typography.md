# 最新稿、字体与局部修改

## 1. 以用户最新稿为源

核对实际打开文件的路径、保存状态和磁盘版本；WPS 也可能运行在 wps.exe。用户已手调后，不从旧 scene 重跑整张图。未保存的用户修改先保留到工作副本，再做限定范围修改。

改字体只改字体，补字只加对应文本；不顺手替换机器人、配色或章节图片。验证变动范围，不覆盖用户其他研究图和论文 PDF。

## 2. 字体

用户指定优先；图片复刻用实际视觉候选匹配，不把某案例的苹方/Times New Roman 规定给所有图片。位图没有字体元数据，不称近似匹配为确切识别。

中英文分别设 `a:ea`、`a:latin`，检查数字、缩写、希腊字母和混排。字体文件存在不等于 Office 已加载。用真实导出观察并在可用时核查 PDF 字体，不只看 XML 名称。不能用字转轮廓解决回退。

```powershell
python scripts/patch_latin_font.py latest.pptx changed.pptx --font 'Times New Roman'
```

该工具用于明确统一整个文件西文字体的任务，另存，不改东亚槽、文本、几何和字号。局部要求需要收窄作用范围。换字体会改变字宽；不能只改字段就保证每个字位置不动。

## 3. 版式

同级字号一致，按语义层级区分。禁止各文本框自动缩成不同字号来塞内容；先用合理换行和留白。图片保持比例，按实际前景统一视觉重量；不得为统一图标而量化颜色或描摹。

## 4. 素材替换

独立图片可以换成更清晰的原文件/API 生成图，保留位置、比例和语义分组。替换后检查边缘、相邻文字和走线。保留原像素，不将图片转曲线。需要编辑内部结构时，应取得真正的源矢量/原生文件。
