# 质量、编辑与交付验收

## 1. 核对来源和像素

最终图片对象逐个对应 assets 清单；无损裁图保留源尺寸/色彩/透明度，不能经过描摹、量化、降采样。API 输出有真实调用、原图、提示词和模型记录。未用到的生成图不能算进最终稿的来源声明。

```powershell
python scripts/audit_pptx.py figure.pptx --expect scene.json --assets-report with-assets.assets.json --output audit.json
```

默认 `components` 模式核对原生文本、独立图片及来源。`full` 是无图片的原生源文件场景；不能把它当目标强迫位图描摹。审计列出图片数量和分辨率，不把独立图片称为原生曲线。

审计核对实际嵌入文件哈希、文本覆盖、分组、连接器引用以及裁剪记录中的禁止描摹/重采样标记。场景可以按输出尺寸设置 min_ppi，但不能用一个 PPI 数字代替查看质量。

## 2. 用目标应用实际导出

以用户使用的 PowerPoint/WPS 为准，导出与原图等尺寸的整图，并查看关键局部。不能只看源 PNG 或浏览器渲染。参考 Windows PowerPoint 的已验证用法：

```python
app = win32com.client.Dispatch('PowerPoint.Application')
p = app.Presentations.Open(absolute_pptx, True, False, False)
p.Slides.Item(1).Export(absolute_png, 'PNG', width_px, height_px)
p.SaveAs(absolute_pdf, 32)
p.Close()
```

只关闭本任务打开的副本，不退出用户有文档的 Office 实例。PDF 导出可能改变打开文件的保存目标，因此在工作副本/只读打开的本任务文件上执行。

检查电极/导线、机器人、波形、头皮图、热图、报告等细节：无色彩坍塌、毛刺、缺口、脏底、截断或过度压缩。显示不清楚就修素材处理链或换更高清源，不能交付一张“结构审计通过”的模糊图。

## 3. 实际编辑抽查

- 修改标题和一个小标签，确认是原生文本。
- 单选一个图标，确认它是独立图片，可移动、裁剪和替换，原图没有跟着整块移动。
- 移动模块，确认已宣称绑定的连接器端点跟随。
- 检查闭环方向、边界和文字避让。

在副本中做，不污染交付稿。图片内部不能编辑节点，应明确说明；不能用几千条追踪路径冒充质量和可编辑性。

## 4. 公开示例和交付

给 PPTX、完整预览和简短编辑能力说明。按需要给场景、独立素材及来源记录；不交旧失败稿。README 用最终实际导出的对比图，清楚注明原生结构与独立素材的区别。公共仓库不含密钥、本机认证配置、私人绝对路径或未获许可的字体文件。

集中完成内容和修改，再统一验收；只有发现新问题时才复查受影响部分，不每放一个图标就全量测试。
