# 用户可配置的图像生成模型

模型选择与 PPT 重建分开。图片来源确定后，后续抠取、原像素嵌入、原生文字和结构流程相同，不依赖某一家生成服务。

## 选择顺序

1. 用户提供准确模型 ID、接口和配置：直接采用，包括自建代理、Nano Banana、Sunburst、GPT Image 或其他模型。
2. 用户只给了模型系列/俗称：结合其已有服务配置、可用模型列表或官方文档确定准确 ID。
3. 用户未指定：采用当前可用图像工具的已配置模型，不把某次任务选择写成技能默认值。

先前指定的模型持续用于当前任务，直到用户更改。不得把 Sunburst、Nano Banana 等品牌名称随意映射成另一模型。

## 匹配接口

- 有支持目标模型的图像工具：使用该工具。
- 用户提供 OpenAI 兼容接口：按该接口实际支持的图片生成/编辑格式调用。
- 模型采用提供者原生接口，例如 Gemini 系列：按官方接口或 SDK 调用，不强塞到仅接受 GPT Image 的 CLI。

尺寸、透明背景、参考图和编辑方式按模型实际能力处理，保存实际返回的原始尺寸。模型选择不改变禁止描摹和保留质量的要求。

## 场景与来源记录

需要 API 生成时，可在场景记录 `image_provider`、`image_model`、`image_api_format`；`image_model` 使用实际准确 ID。接口和凭据从用户提供的配置读取，密钥不写入场景、提示词或仓库。

`generation.json` 记录实际 model/provider、调用方法、原始输出、提示词和哈希。不同提供者的响应统一整理为这份来源记录，PPT 组装脚本继续使用图片文件。
