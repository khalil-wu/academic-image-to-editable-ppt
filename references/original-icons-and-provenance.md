# 抠取、API 原创与来源

## 1. 严禁描摹，不因来源改变

用户原图、网上图片、自己新生成的图片，均不能使用路径追踪、轮廓矢量化、手工描画或逐像素拼块。图标表裁剪后直接作为高清图片对象使用。由 API 生成不代表之后可以把它描摹成路径。

## 2. 选择来源

| 用户要求 | source_type | 处理 |
| --- | --- | --- |
| 沿用原图 / 允许抠取 | source-crop | 无损裁剪，保留原始像素 |
| 原创 / 指定 API 模型 | api-generated-original | 实际调用，使用新输出像素 |
| 已有合法源资产 | licensed-original | 原文件直接使用，记录来源 |

源图不是原始高分辨率文件时，先看实际输出需求。够清楚就保留；不够就找高清源或按授权重新生图，不能偷偷走描摹。原始实验图表不能靠模型编出更漂亮的数据。

## 3. 真实生成记录

模型可用列表、dry-run、复制旧图片都不算已生成。只有实际成功调用和输出才可宣称“使用了 API”。保存原始图片、实际提示词、模型 ID、输出尺寸和哈希；不保存密钥、认证头或私人配置。

```json
{
  "method":"imagegen-cli-generate",
  "model":"用户实际选择的模型",
  "api_call_completed":true,
  "outputs":[{"file":"icons.png","sha256":"实际值","prompt_file":"prompt.txt","prompt_sha256":"实际值"}]
}
```

记录不能补造调用事实；交付时应能指向真实工具执行和原始生成结果。用户要求不临摹时，生成提示词描述语义与风格，不把别人的图标作为编辑目标。

## 4. 抠图记录

`crop_assets.py` 自动记录源文件、源哈希、裁剪坐标、输出像素、清除矩形和输出哈希，明确 `traced=false`、`resampled=false`、`palette_quantized=false`。公开工程可把本机路径替换为包内相对路径，但不能修改源图片或捏造生成来源。

各素材标记抠取还是 API 生成；不能把抠取素材称为原创，也不能把未使用的生成结果算成最终稿已经使用。
